# Фронтенд

Один Nuxt 4 проект: `vsluh-frontend/web`. Он же лендинг, он же Telegram Mini App.

## Дизайн-токены

Сняты замером с эталона `froze-chomp-91118995.figma.site` и лежат готовыми
классами в `app/assets/css/tailwind.css`. Менять значения без сверки с макетом нельзя.

| Что             | Значение                           |
| --------------- | ---------------------------------- |
| Фон страницы    | `#f3f6fa` + два градиента `app-shell` |
| Текст           | `#0a1020`, вторичный `#718096`     |
| Акцент          | `#5ea9ff`, ссылки `#408fdc`        |
| Чип             | `#ffffff9e`, рамка `#0a102012`     |
| Выбранный чип   | `#7dbbff6b`, рамка `#5ea9ffad`     |
| Пилюли          | `border-radius: 999px`             |
| Шрифт           | Manrope 400–700                    |
| Заголовок       | `clamp(38px, 5.2vw, 54px)`, `-0.055em` |

`line-height` задан относительным (`1.5`) — потомки масштабируют его от своего
`font-size`. С абсолютным значением разъезжаются шапка, футер и мета-строка.

## Экраны

| Стадия     | Класс              | Что показывает                         |
| ---------- | ------------------ | -------------------------------------- |
| `topics`   | `screen--topics`   | Выбор режима, тем и настроения         |
| `wheel`    | `screen--wheel`    | Барабан из 18 строк                    |
| `prepare`  | `screen--prepare`  | Таймер подготовки                      |
| `speak`    | `screen--speak`    | Таймер речи                            |
| `finished` | `screen--finished` | «Готово» и выбор следующего действия   |

Стадию держит `usePractice()`; разводит экраны `app/pages/index.vue`.

## Барабан

Геометрия из макета: 18 строк по 120px (108px на мобиле), подсветка стартует
на 3-й строке, финиширует на 15-й — отсюда `--wheel-start-offset: -300px`
и `--wheel-end-offset: -1740px`.

Пока идёт CSS-анимация, `requestAnimationFrame` читает `transform` списка и
вычисляет, какая строка физически в центре. На каждую пройденную строку —
щелчок, и на неё же переезжает `wheel-row--selected` (центральная строка чёрная,
соседние выцветают по `--distance-N`).

Остановку ловим по `animationend`. Есть страховочный таймер: в фоновой вкладке
анимация не доигрывает и событие не приходит.

## Звук

Синтезируется через Web Audio API в `shared/lib/sound.ts`, файлов нет.

- щелчок — `triangle`, 1120 → 760 Гц за 25 мс;
- остановка — аккорд из четырёх `sine`: 740 / 1485 / 2240 / 2965 Гц.

`AudioContext` создаётся лениво и будится `resume()` — иначе автоплей-политика
браузера его глушит.

## Telegram

Внутри мессенджера работает та же сборка. Признак среды — `window.TelegramWebviewProxy`
или `tgWebApp` в хэше; SDK подгружается динамически только там — на лендинге запроса
к `telegram.org` нет вообще.

Плагин вешает класс `is-telegram` на `<html>` — через него и делаются отличия
(сейчас — скрытый футер). Реактивный бинд здесь не годится: плагин дожидается внешнего
SDK и отрабатывает после гидрации, а Vue уже не патчит статичный `class` на корне лейаута.
