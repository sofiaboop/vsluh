# Фронтенд

Два Nuxt 4 приложения с общей структурой: `vsluh-frontend/web` (лендинг) и
`vsluh-miniapp/web` (Telegram Mini App). Различия — только в авторизации и шапке.

## Дизайн-токены

Сняты с макета Figma и зафиксированы в `tailwind.config.js`. В разметке используем
только токены, произвольные hex запрещены.

| Токен            | Значение                        | Где                          |
| ---------------- | ------------------------------- | ---------------------------- |
| `canvas`         | `#F3F6FA`                       | фон страницы                 |
| `ink`            | `#0A1020`                       | основной текст               |
| `ink-muted`      | `#344157`                       | переключатель режимов        |
| `ink-soft`       | `#5B6880`                       | подписи                      |
| `brand`          | `#408FDC`                       | акцент, активная кнопка      |
| `brand-strong`   | `#327FC8`                       | текст выбранного чипа        |
| `brand-border`   | `#7DBBFF`                       | рамка выбранного чипа        |
| `bg-chip`        | `rgba(255,255,255,.62)`         | фон чипа                     |
| `border-chip`    | `rgba(10,16,32,.07)`            | рамка чипа                   |
| `shadow-chip`    | `0 6px 17px rgba(31,54,83,.035)`| тень чипа                    |
| `rounded-pill`   | `999px`                         | все пилюли                   |

Шрифт — Manrope (400–800), подключён через `@nuxtjs/google-fonts` с локальным
скачиванием, внешних запросов в рантайме нет.

Заголовок: `text-display` = `clamp(2.25rem, 4.7vw, 5rem)`, вес 500,
`tracking-display` = `-0.055em`.

## Слои

```
app/
├── pages/        тонкие роуты
├── widgets/      SiteHeader, SiteFooter, BackdropGlow
├── features/     topic-picker/ui/TopicPicker.vue
├── entities/     доменные сущности
├── components/   базовый UI: BaseChip, BaseToggle, LogoMark
└── shared/       constants/, lib/, api/
```

Компоненты из `components/`, `widgets/` и `**/ui/**` регистрируются автоматически
(см. `components` в `nuxt.config.ts`) — импортировать их вручную не нужно.

## Состояние лендинга

MVP: функционала практики нет. «Продолжить» активируется при выборе хотя бы одной темы
и показывает заглушку. Логика выбора живёт в `TopicPicker.vue`, переносить её в Pinia
имеет смысл только когда появится переход на экран практики.
